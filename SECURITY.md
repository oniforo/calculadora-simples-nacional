# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅ |
| < latest | ❌ |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report it privately via one of:

- GitHub's private vulnerability reporting (Security tab → "Report a
  vulnerability" on this repo, if enabled)
- Email: g.orofino@protonmail.com

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, PoC code, or affected versions

We aim to acknowledge reports within a few business days and will keep you
updated as the issue is investigated and resolved.
